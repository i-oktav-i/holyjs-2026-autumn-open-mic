Bit Masking

Зачем?

Есть объекты с признаками

Тип данных

const atms: {
  id: string;
  features: {
    workingNow: boolean;
    supportsNFC: boolean;
    qrCodeWithdraw: boolean;
    /* ... */
  };
}[];

Как мы отфильтруем по нужному набору фильтров

Фильтрация данных

const targetFilters = {/*  */};
const targetFiltersKeys = Object.keys(targetFilters);
const filtered = atms.filter((atm) =>
  targetFiltersKeys.each((key) => {
    const featureValue = atm.features[key];
    return !targetFilters[key] || featureValue === targetFilters[key];
  }),
);

Bit Masking позволяет компактно хранить и работать с наборами признаков

Как это работает?

За каждым признаком закрепляется бит в двоичном представлении числа

Маски

const masks = {
  workingNow: 1 << 0, // 001
  supportsNFC: 1 << 1, // 010
  qrCodeWithdraw: 1 << 2, // 100
};

Для работы с ними используются побитовые операции

Объявим три утилиты для работы

Утилиты работы с масками

const combine = (...flags) => flags.reduce((mask, flag) => mask | flag, 0);

const exclude = (mask, toExclude) => mask & ~toExclude;

const isMatch = (mask, required) => (mask & required) === required;

Обновленный код

const atms: {
  id: string;
  featuresMask: number;
}[];

const targetFilter = combine(/*  */);

const filtered = atms.filter((atm) => isMatch(atm.featuresMask, targetFilter));
